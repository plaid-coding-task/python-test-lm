# Python Live Coding Assignment

**Duration:** 5–10 minutes  
**Language:** Python 3

---

## Overview

Complete all three tasks in the provided files. Each file contains a function stub with a docstring describing what it should do. Write your implementation inside the function body.

Run each file to verify your output matches the expected result shown in the `if __name__ == "__main__"` block at the bottom of each file.

---

## Tasks

### Task 1 — `task1.py`: FizzBuzz Filter
Write a function that processes a list of integers and returns a new list where:
- Multiples of 3 are replaced with `"Fizz"`
- Multiples of 5 are replaced with `"Buzz"`
- Multiples of both 3 and 5 are replaced with `"FizzBuzz"`
- All other numbers remain unchanged

---

### Task 2 — `task2.py`: Word Frequency Counter
Write a function that takes a string sentence and returns a dictionary where each key is a unique word (case-insensitive) and each value is how many times that word appears in the sentence.

---

### Task 3 — `task3.py`: Flatten Nested List
Write a function that takes a nested list (up to any depth) and returns a single flat list containing all the values in order.

---

## Rules

- Do **not** use any external libraries — standard Python only.
- Do **not** modify the function signatures or the test block at the bottom of each file.
- Your solution must pass the assertions in each file without errors.

---

## How to Run

```bash
python task1.py
python task2.py
python task3.py
```

A passing solution prints `All tests passed!` for each file.
